作成：2026-10-21（Claude Code 調べ）。採否は発注者が決める。採用したものは `content/resources.yaml` に入れ、公開直前に公式ページで番号・受付時間・URL を再確認する（§10.6）。

「確認」の列：
- **公式**：運営元（国・自治体・運営団体）の公式ページ、または国の事務連絡で確認した
- **二次**：報道・自治体の案内ページで確認した。運営元の公式ページでの確認がまだ必要

番号・受付時間は変わることがあるため、画面では「受付時間は公式ページで確認してください」と添える。
